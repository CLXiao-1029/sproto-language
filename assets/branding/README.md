# SProto branding

- `icon.png`: standalone generated icon (transparent PNG).
- `icon-256.png`: 256 × 256 extension icon.
- `logo.png`: horizontal logo (transparent PNG, dark lettering for light backgrounds).
- `brand-sheet.png`: original icon and logo composition.

VS Code uses `vscode/images/icon.png`; its README uses `vscode/images/logo.png`.
Rider includes the logo under `branding/` and a compact vector rendition of the mark at `META-INF/pluginIcon.svg` for the plugin list.

The Rider plugin-list icon is 40 × 40; file tabs, project-tree entries, and color-settings pages use the separate 16 × 16 SVG at `icons/sprotoFile.svg`.

The PNG artwork was generated with OpenAI ImageGen. The SVG is a simplified adaptation for small IDE icons.
